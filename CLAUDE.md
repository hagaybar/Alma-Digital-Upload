# CLAUDE.md

Uploads digital files to Alma: creates representations and links S3 files to them
(`alma_digital_upload.py`). Run manually on masedet; it writes to Alma. See `docs/README.md`.

## almaapitk bumps

Any change to the `almaapitk` pin follows `docs/almaapitk-bump-protocol.md` (binding): one bump
at a time, from this repo, with an audit in `docs/almaapitk-<version>-audit.md`.
